# Centro Cultural Puerto Abierto

Proyecto desarrollado para el Certamen N°1 de Aplicaciones Web.

## Descripción

Sitio web estático desarrollado para el Centro Cultural Puerto Abierto, una organización dedicada a promover actividades artísticas, culturales y educativas para la comunidad.

El sitio permite conocer las actividades disponibles y acceder al formulario de inscripción.

## Tecnologías utilizadas

- HTML5
- CSS3
- Bootstrap 5

## Páginas

- Página Principal
- Cartelera de Actividades
- Inscripción a Actividades
